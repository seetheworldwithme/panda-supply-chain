## 本轮变更

- 租售 `/busEnterpriseLeasing/add` 与 `/updateById` 接入 Java 对应的专用保存逻辑；模板列表、删除等端点保持原注册。
- 煤种搜索从近似切词切换为 HanLP portable-1.8.4 原生实现。与本机同版本 Java JAR 对照的 92 条煤种、指标、人名、地址、数字、符号和混合文本样例全部一致，运行 Go 服务不依赖 JVM。
- 微信/手机号登录及用户资料更新按 Java 写入 `userId{id}` Redis hash；普通表单登录仍不写该 hash。

- `go vet ./...`、`go build ./...`：通过。
- Python validation 单元测试：6 项通过。
- `route_audit_test.go` 对照服务器运行 Java 的 1602 条路由清单，所有已盘点路由均要求 Go 注册；本轮全量 Go 测试通过。
- 旧前端在隔离数据库与临时账户下登录 Go，本机代表页面的 6 个 API 请求均为 HTTP 200 / code 200。请求记录和截图见同目录 `browser-requests.json`、`old-frontend-orders.png`。

## 验收边界

- 微信支付、银行、通联、电子签章、短信及 OCR/QCC 的协议和业务测试使用本地 fake endpoint；未验证真实商户、银行或第三方账户的端到端成功交易。
- 浏览器只覆盖代表页面的读取流程，不代表所有写入流程、角色权限、租售操作、分库选择和全部页面均已验收。
- 未在生产环境启动 Java/Go 对照、未写远端数据库、未部署或切换后端。
- Redis 会员到期监听依赖运行环境已启用 Redis expired keyevent；本轮没有更改服务器 Redis 配置。

因此，这些结果证明本地构建、自动化契约和代表性前端读取验证通过，不等于生产切换已完成。
